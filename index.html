Waypoint Teleport Mod

Erstelle unendlich viele Wegpunkte und reise blitzschnell durch deine Minecraft-Welt!

✨ Features

  • Einfaches Erstellen: Speichere deine aktuelle Position mit einem simplen Befehl ab.
  • Sofortiger Teleport: Kehre jederzeit auf Knopfdruck oder per Chat zu deinen Wegpunkten zurück.
  • Übersichtliche Liste: Verwalte all deine Basen, Minen und Portale an einem zentralen Ort.
  • Kompatibilität: Funktioniert reibungslos im Singleplayer und auf Servern.

⌨️ Steuerung & Befehle

Nutze die folgenden Chat-Befehle im Spiel, um die Mod zu steuern:

Wegpunkt setzen:

/wp set [Name]

Zu einem Punkt teleportieren:

/wp tp [Name]

Liste aller Punkte anzeigen:

/wp list

⚙️ Installation

  1. Stelle sicher, dass du die passende Version von Forge oder Fabric installiert hast.
  2. Lade die Mod-Datei (JAR) über den Button unten herunter.
  3. Verschiebe die heruntergeladene Datei in deinen .minecraft/mods-Ordner.
  4. Starte Minecraft und genieße das schnelle Reisen!
